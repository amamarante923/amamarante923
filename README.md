### 💫 Sobre Mim

Olá! Sou o **André**, desenvolvedor web fullstack. Trabalho com tecnologia desde 2020 e atualmente, faço parte do time do **Serpro**, a maior empresa pública de tecnologia da informação do mundo, onde trabalho desenvolvendo e mantendo sistemas críticos para o governo federal brasileiro.

- 💻 Minhas linguagens principais são **Python**, **Java** e **TypeScript**.
- 🛠️ Tenho forte interesse em desenvolvimento backend, automação de processos e APIs RESTful.
- ⚙️ Adoro aprender novas tecnologias e boas práticas de engenharia de software para aplicar no dia a dia.
